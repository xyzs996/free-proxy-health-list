## 💡 Зачем этот проект

Некоторое время назад я писал небольшой скрапер для отслеживания цен. С одного IP запросы постоянно упирались в лимиты, и я пошёл искать бесплатные прокси. Все списки рассказывали одну и ту же историю: половина записей мертва, те, что с пометкой «обновляется ежедневно», не менялись месяцами, а сайты с рабочими прокси требовали карту ещё до того, как дадут что-то проверить.

Автоматические проверки для собственного скрапинга у меня уже работали, поэтому я начал публиковать результаты — бесплатный список прокси, который **действительно проверен**, перепроверяется каждые 30 минут и доступен по стабильной CDN-ссылке. Без регистрации, без карты, без личного кабинета. Вот и всё. Если это сэкономит вам тот вечер, который потерял я, звезда поможет следующему разработчику его найти. Данные бесплатны в любом случае.

## 🧱 Формат данных

`data.txt` — по одному `host:port` в строке. `data.json` несёт метаданные проверки для каждой записи:

```json
{
  "proxy": "203.0.113.10:8080",
  "host": "203.0.113.10",
  "port": 8080,
  "protocol": "http",
  "latencyMs": 842,
  "qualityScore": 91,
  "checkType": "http_probe",
  "supportsHttps": true,
  "country": "US",
  "anonymity": "elite",
  "consecutiveSuccesses": 4,
  "reliabilityScore": 96.75,
  "reliabilitySamples": 41,
  "lastChecked": "2026-07-25T11:09:35Z"
}
```

Читаете программой? [`llms.txt`](https://xyzs996.github.io/free-proxy-health-list/llms.txt) отдаёт весь снимок одним запросом — каждый список с его количеством, ссылками на скачивание и датой проверки.

## ❓ Частые вопросы

<details>
<summary><strong>Безопасны ли эти бесплатные прокси?</strong></summary>

Бесплатные публичные прокси общие, и управляют ими неизвестные операторы, поэтому не передавайте через них пароли, токены и личные данные. Они подходят для тестов, парсинга публичных страниц и автоматизации, но не для чувствительного трафика.
</details>

<details>
<summary><strong>Как часто обновляется список?</strong></summary>

Каждый прокси перепроверяется, а список публикуется заново каждые 30 минут. В каждой JSON-записи есть lastChecked и задержка, чтобы вы сами отбрасывали устаревшие или медленные записи.
</details>

<details>
<summary><strong>Что здесь значит «проверенный»?</strong></summary>

Каждая запись прошла корректное для протокола рукопожатие и сквозную пересылку реального запроса до публикации. Записи, которые только приняли TCP-соединение, не публикуются.
</details>

<details>
<summary><strong>Почему некоторые прокси перестают работать за минуты?</strong></summary>

Бесплатные прокси нестабильны по своей природе: они постоянно появляются и исчезают. Именно поэтому список перепроверяется каждые 30 минут и сортируется по скорости. Всегда переходите к следующей записи при сбое.
</details>

<details>
<summary><strong>Какой тип прокси выбрать?</strong></summary>

HTTP проще всего для веб-запросов. SOCKS5 поддерживает любой TCP-трафик, а также UDP и удалённый DNS. SOCKS4 — лёгкий устаревший вариант. Записи HTTPS — это HTTP-прокси с подтверждённым TLS-туннелем.
</details>

<details>
<summary><strong>Нужно ли регистрироваться или ставить звезду?</strong></summary>

Нет. Это полностью публичный срез по стабильным URL, без аккаунта и без карты. Звезда лишь помогает другим разработчикам его найти.
</details>
