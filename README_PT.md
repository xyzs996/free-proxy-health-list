## 💡 Por que este projeto?

Tempos atrás eu estava construindo um scraper de acompanhamento de preços. Cada execução acabava limitada a partir do meu único IP, então fui atrás de proxies gratuitos. Todas as listas contavam a mesma história: metade das entradas estava morta, as que diziam "atualizado diariamente" não mudavam havia meses, e os sites com proxies funcionando pediam cartão antes mesmo de eu testar um.

Eu já rodava verificações automáticas para o meu próprio scraping, então comecei a publicar os resultados: uma lista de proxies grátis **de fato verificada**, rechecada a cada 30 minutos e disponível em um link de CDN estável. Sem cadastro, sem cartão, sem painel. É só isso. Se economizar a tarde que eu perdi, uma estrela ajuda o próximo desenvolvedor a encontrá-la. Os dados são grátis de qualquer forma.

## 🧱 Formato dos dados

`data.txt` traz um `host:port` por linha. `data.json` carrega os metadados de saúde de cada entrada:

```json
{
  "proxy": "203.0.113.10:8080",
  "host": "203.0.113.10",
  "port": 8080,
  "protocol": "http",
  "latencyMs": 842,
  "qualityScore": 91,
  "checkType": "http_probe",
  "supportsHttps": true,
  "country": "US",
  "anonymity": "elite",
  "consecutiveSuccesses": 4,
  "reliabilityScore": 96.75,
  "reliabilitySamples": 41,
  "lastChecked": "2026-07-25T11:09:35Z"
}
```

Está lendo com um programa? [`llms.txt`](https://xyzs996.github.io/free-proxy-health-list/llms.txt) entrega o instantâneo inteiro em uma única requisição: cada lista com sua contagem, suas URLs de download e a data da verificação.

## ❓ Perguntas frequentes

<details>
<summary><strong>Esses proxies gratuitos são seguros?</strong></summary>

Proxies públicos gratuitos são compartilhados e operados por desconhecidos, então nunca envie senhas, tokens ou dados pessoais por eles. Use-os para testes, coleta de páginas públicas e automação — não para tráfego sensível.
</details>

<details>
<summary><strong>Com que frequência a lista é atualizada?</strong></summary>

Cada proxy é reverificado e a lista republicada a cada 30 minutos. Cada registro JSON traz lastChecked e a latência, para você mesmo descartar entradas antigas ou lentas.
</details>

<details>
<summary><strong>O que significa 'verificado' aqui?</strong></summary>

Cada entrada completou um handshake correto para o protocolo e retransmitiu uma requisição real de ponta a ponta antes da publicação. Entradas que apenas aceitaram uma conexão TCP não são publicadas.
</details>

<details>
<summary><strong>Por que alguns proxies param de funcionar em minutos?</strong></summary>

Proxies gratuitos são voláteis por natureza: surgem e somem o tempo todo. É justamente por isso que a lista é reverificada a cada 30 minutos e ordenada do mais rápido para o mais lento. Sempre siga para a próxima entrada ao falhar.
</details>

<details>
<summary><strong>Qual tipo de proxy devo usar?</strong></summary>

HTTP é o mais simples para requisições web. SOCKS5 lida com qualquer tráfego TCP, além de UDP e DNS remoto. SOCKS4 é uma alternativa leve e legada. As entradas HTTPS são proxies HTTP verificados para tunelar TLS.
</details>

<details>
<summary><strong>Preciso me cadastrar ou dar uma estrela ao repositório?</strong></summary>

Não. A lista é um snapshot totalmente público em URLs estáveis, sem conta e sem cartão. A estrela apenas ajuda outros desenvolvedores a encontrá-la.
</details>
