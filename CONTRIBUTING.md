# Contributing

Thanks for helping improve the public ProxyHealthList data repository.

## Ways to Contribute

- Report broken output files.
- Add examples for developer tools.
- Improve documentation and translations.
- Suggest public data usability improvements.

## Pull Requests

1. Keep PRs focused.
2. Do not add sources with unclear redistribution terms.
3. Do not add code that bypasses access controls or targets a specific third-party service for evasion.
4. Keep public-facing documentation clear and user-focused.

The collection pipeline is maintained separately from this public repository.
