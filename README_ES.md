## 💡 ¿Por qué este proyecto?

Hace un tiempo estaba construyendo un scraper de seguimiento de precios. Cada ejecución acababa limitada desde mi única IP, así que busqué proxies gratuitos. Todas las listas contaban lo mismo: la mitad de las entradas estaban muertas, las que decían "actualizado a diario" llevaban meses sin moverse, y los sitios con proxies que funcionaban pedían una tarjeta antes de dejarme probar uno.

Ya ejecutaba comprobaciones automáticas para mi propio scraping, así que empecé a publicar los resultados: una lista de proxies gratis **realmente verificada**, revisada cada 30 minutos y descargable desde un enlace CDN estable. Sin registro, sin tarjeta, sin panel. Eso es todo. Si te ahorra la tarde que yo perdí, una estrella ayuda al siguiente desarrollador a encontrarla. Los datos son gratis igual.

## 🧱 Estructura de datos

`data.txt` contiene un `host:port` por línea. `data.json` añade los metadatos de salud de cada entrada:

```json
{
  "proxy": "203.0.113.10:8080",
  "host": "203.0.113.10",
  "port": 8080,
  "protocol": "http",
  "latencyMs": 842,
  "qualityScore": 91,
  "checkType": "http_probe",
  "supportsHttps": true,
  "country": "US",
  "anonymity": "elite",
  "consecutiveSuccesses": 4,
  "reliabilityScore": 96.75,
  "reliabilitySamples": 41,
  "lastChecked": "2026-07-25T11:09:35Z"
}
```

¿Lo lees con un programa? [`llms.txt`](https://xyzs996.github.io/free-proxy-health-list/llms.txt) entrega la instantánea completa en una sola petición: cada lista con su recuento, sus URL de descarga y la fecha de verificación.

## ❓ Preguntas frecuentes

<details>
<summary><strong>¿Son seguros estos proxies gratuitos?</strong></summary>

Los proxies públicos gratuitos son compartidos y los gestionan operadores desconocidos, así que nunca envíes contraseñas, tokens ni datos personales a través de ellos. Úsalos para pruebas, scraping de páginas públicas y automatización, no para tráfico sensible.
</details>

<details>
<summary><strong>¿Con qué frecuencia se actualiza la lista?</strong></summary>

Cada proxy se vuelve a comprobar y la lista se republica cada 30 minutos. Cada registro JSON incluye lastChecked y la latencia, para que descartes tú mismo las entradas obsoletas o lentas.
</details>

<details>
<summary><strong>¿Qué significa aquí «verificado»?</strong></summary>

Cada entrada completó un handshake correcto para su protocolo y retransmitió una petición real de extremo a extremo antes de publicarse. Las entradas que solo respondieron a una conexión TCP no se publican.
</details>

<details>
<summary><strong>¿Por qué algunos proxies dejan de funcionar en minutos?</strong></summary>

Los proxies gratuitos son volátiles por naturaleza: aparecen y desaparecen constantemente. Por eso la lista se revisa cada 30 minutos y se ordena de más rápido a más lento. Pasa siempre al siguiente cuando uno falle.
</details>

<details>
<summary><strong>¿Qué tipo de proxy debería usar?</strong></summary>

HTTP es lo más simple para peticiones web. SOCKS5 admite cualquier tráfico TCP, además de UDP y DNS remoto. SOCKS4 es una alternativa ligera y antigua. Las entradas HTTPS son proxies HTTP verificados para tunelizar TLS.
</details>

<details>
<summary><strong>¿Hay que registrarse o dar una estrella al repositorio?</strong></summary>

No. La lista es una instantánea totalmente pública en URLs estables, sin cuenta y sin tarjeta. La estrella solo ayuda a que otros desarrolladores la encuentren.
</details>
